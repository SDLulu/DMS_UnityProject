## 전체 구조

- 사운드 재생 매니저: `Assets/_WIP/yongwoo/Scripts/Managers/Audio/YongwooAudioManager.cs`
- 사운드 파일 위치: `Assets/_WIP/yongwoo/Resources/Yongwoo/SFX`
- 코드 호출 방식: `YongwooAudioManager.Play(YongwooSfxId.이름, 볼륨, 피치랜덤)`
- Unity 로드 방식: `Resources.Load<AudioClip>("Yongwoo/SFX/파일명")`

## 조절은 어디서 하나?

### 1. 소리 자체를 바꾸고 싶을 때

이 폴더의 `.wav` 파일을 같은 이름으로 교체한다.

예:
- `플레이어_칼휘두르기.wav`를 더 좋은 칼 휘두르는 소리로 교체
- `타이핑_글자틱.wav`를 더 부드러운 키보드/터미널 tick으로 교체
- `보스_패턴발동.wav`를 더 무거운 보스 공격음으로 교체

파일명만 유지하면 `YongwooAudioManager.cs` 수정은 필요 없다.

### 2. 특정 소리 볼륨을 바꾸고 싶을 때

각 호출부의 두 번째 인자를 바꾼다.

예:

```csharp
YongwooAudioManager.Play(YongwooSfxId.SwordSwing, 0.62f, 0.05f);
```

- `0.62f` = 볼륨
- `0.05f` = 피치 랜덤 폭

볼륨 기준:
- `0.2 ~ 0.4` = 작은 UI / 타이핑
- `0.5 ~ 0.7` = 일반 액션
- `0.75 이상` = 사망 / 보스 / 큰 이벤트

### 3. 같은 소리가 반복돼서 귀가 피곤할 때

피치 랜덤 값을 조금 올린다.

예:

```csharp
YongwooAudioManager.Play(YongwooSfxId.HitLight, 0.72f, 0.08f);
```

- 타격음, 타이핑음, 보스 발사음처럼 자주 반복되는 소리에 효과적
- 너무 높이면 장난감처럼 들리므로 보통 `0.03 ~ 0.08` 안에서 조절

### 4. 타이핑 속도 / 타이핑음 빈도를 바꾸고 싶을 때

인스펙터에서 조절:

- 시스템로그: `SystemLogPanel`
- 브로커통신/대화: `CommsPanel`

주요 값:
- `Use Typewriter`: 타이핑 효과 켜기/끄기
- `Characters Per Second`: 초당 출력 글자 수
- `Max Typing Duration Ratio`: 기존 대사 duration 중 타이핑에 쓸 최대 비율
- `Typing Sound Every Characters`: 몇 글자마다 tick 소리를 낼지

추천 시작값:
- 시스템로그: 빠르게, `Characters Per Second` 42 이상
- 브로커통신: 조금 느리게, `Characters Per Second` 32~40
- 타이핑음이 많으면 `Typing Sound Every Characters`를 3~4로 올리기

### 5. 전체 사운드 볼륨을 한 번에 낮추고 싶을 때

현재는 `YongwooAudioManager`가 런타임에 자동 생성된다. 빠르게 조절하려면 코드의 기본 볼륨 또는 각 호출부 볼륨을 조절한다.

나중에 전체 믹서를 제대로 잡을 때는 다음 중 하나로 확장하면 좋다:

- `YongwooAudioManager`를 씬에 직접 배치하고 `Master Volume`을 인스펙터에서 조절
- Unity `AudioMixer`를 추가해서 `UI`, `Player`, `Enemy`, `Boss`, `Ambience` 그룹으로 분리
- 임시 WAV를 최종 SFX로 교체한 뒤 전체 볼륨 밸런스 재조정

## 우선 들어보면서 체크할 순서

1. 타이틀 시작음이 너무 크거나 튀지 않는지
2. 시스템로그/브로커통신 타이핑 속도가 기존 대사 duration 안에서 자연스러운지
3. `타이핑_글자틱.wav`가 너무 자주 들리지 않는지
4. 칼 휘두르기 + 공통 적중음이 겹쳤을 때 과하게 크지 않은지
5. 점프/대시/롤이 조작감에 맞게 짧게 붙는지
6. 보스 텔레그래프/발사음이 너무 반복적으로 피곤하지 않은지
7. 보스 페이즈 전환/최종 처치음이 충분히 크지만 대사를 덮지 않는지

---

## 현재 주의점

- 이 문서와 WAV는 `Resources` 폴더 안에 있으므로 빌드에 포함될 수 있다. 최종 배포 전에는 문서를 다른 문서 폴더로 옮기거나 빌드 포함 여부를 확인한다.
- 임시 WAV는 전부 코드로 만든 단순 합성음이다. 최종 퀄리티 사운드가 아니다.
- Unity refresh/play 청감 검증은 아직 필요하다.
