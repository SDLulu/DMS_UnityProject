# DEEP DIVE: HOME — 세계관

> 게임 정체성·핵심 용어·등장 인물·톤. 구체 흐름과 연출 시퀀스는 `시나리오.md`, 보스 스토리/대사는 `보스시나리오.md`, 보스전 게임플레이 룰은 `보스전로직.md`로 분리.

---

## 게임 정체성

- 제목: **DEEP DIVE: HOME**
- 장르: 슈퍼핫 시간 메카닉 + 카타나제로 2D 액션 (심상세계 SF)
- 한 줄 컨셉: **의뢰주가 지정한 두뇌 칩에 침투해 데이터를 회수하는 딥 다이버의 한 차례 작업**
- 톤: 무심·건조·짧은 대사. 승리감/감정 격화는 회피. 사람을 데이터로 다루는 사회의 차가운 무게감

---

## 핵심 용어

| 용어 | 의미 |
|---|---|
| **딥 다이버** | 타인의 두뇌 칩/기억층에 침투해 데이터를 회수하는 직업. 주인공의 직업 |
| **두뇌 칩** | 시민 머리에 박힌 통신·시야·기억 인터페이스. 사후에도 일부 데이터가 남는다 |
| **회수** | 의뢰주가 지정한 파일을 두뇌 칩에서 빼내는 작업 |
| **HOME** | 본작의 회수 대상 파일명. 의뢰주는 거주권 키로 오해하나 실제는 가족 기억 백업 |
| **접속 / 심층** | 회수 작업의 단계. 표층은 정리된 데이터, 심층은 인격 잔재가 남은 영역 |
| **잔류 인격** | 사망/의식 붕괴된 인물의 두뇌 칩에 남은 마지막 의지. 보스의 정체 (상세: `보스시나리오.md`) |
| **채무자** | 도시 시스템 안에서 빚을 진 사람. 회수 작업 대상이 되기도 함 |

---

## 게임 안 인터페이스 (in-game 표현)

> 이 세 가지는 단순 UI가 아니라 세계관 안에서 각각 의미가 있다.

| 시스템 | 세계관 내 의미 | 시각 표현 |
|---|---|---|
| **시스템로그** | 주인공 머릿속 칩이 보내는 자체 메시지. 시야 안에 뜨는 텍스트 | 작은 UI 텍스트 오버레이. 기본 배경 없음 |
| **브로커통신** | 외부 의뢰주에게서 들어오는 음성 통신 | 화면 하단/모서리 대사창 (Speaker + Line) |
| **ScreenFade** | 의식 전환·접속 시작/종료의 시각 표현 | 검은색 전체 화면. 짧은 전환에만 사용 |

> 시스템로그 자체는 검은 배경을 동반하지 않는다. 화면을 가려야 할 때만 별도 ScreenFade로 검게 한다.

## 등장 인물

| 이름 | 역할 | 비고 |
|---|---|---|
| **주인공** | 딥 다이버. 머리에 통신/시야 인터페이스 칩이 박혀 있음 | 직접 조작 캐릭터. 톤은 무심·짧은 단정형 |
| **브로커** | 의뢰주. 외부에서 통신으로만 등장 | CommsPanel 초상화 1종. 톤은 냉정·돈 중심·감정 무시 |
| **광장 NPC** | 노점상 / 안내 AI / 행인 | 광장 구역. 정보 제공·거주민 묘사 |
| **잔류 인격 (보스)** | HOME 파일을 지키기 위해 남은 채무자 047의 마지막 의지 | 보스전 등장. 상세 lore와 대사는 `보스시나리오.md` |

## 주요 가치 대비

> 게임 전체를 관통하는 두 시선의 충돌. 보스전 = 이 대비의 전환점.

| 브로커가 보는 세계 | 주인공이 차츰 보게 되는 세계 |
|---|---|
| 기억 = 돈 되는 데이터 | 기억 = 누군가의 삶 |
| 회수 대상 = 단순 작업 항목 | 회수 대상 = 사람이었다 |
| "추억은 싸. 암호는 비싸고." | (말 없음, 침묵으로 응답) |

## 톤 가이드 요약

- **주인공**: 무심, 짧은 말, 단정형. 예: "늘 하던 대로.", "보여.", "다음.", "...이걸로 하루."
- **브로커**: 냉정, 돈 중심. 예: "추억은 싸. 암호는 비싸고."
- **잔류 인격(보스)**: 흐릿하지만 분명한 의지. 짧고 끊기는 말투. 예: "그건 팔 물건이 아니야."

상세 보스 톤·대사는 `보스시나리오.md` 톤 가이드 섹션.
