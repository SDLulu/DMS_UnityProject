# DEEP DIVE: HOME — 시나리오

> 구현 기준 문서. 이 흐름을 기준으로 튜토리얼 시퀀스와 씬 이벤트를 맞춘다.

---

## 컨셉

| 시스템 | 역할 | 시각 |
|---|---|---|
| **시스템로그** | 머릿속 칩이 보내는 메시지 (자기 시야 안에 뜨는 텍스트) | 작은 UI 텍스트 오버레이. 배경 없음. |
| **브로커통신** | 외부에서 들어오는 음성 통신 | 화면 하단/모서리 대사창 (Speaker + Line) |
| **ScreenFade** | 화면 전환 효과 | 검은색 전체 화면. 짧은 전환에만 사용. |

> **주의**: 시스템로그 자체는 배경 검은 화면을 동반하지 않음. 인트로 "접속 중" 연출처럼 화면을 가려야 할 때만 별도 ScreenFade(또는 인트로 전용 backdrop)로 검게 함.

---

## 등장 인물

- **주인공**: 직업은 딥 다이버. 타인의 두뇌 칩/기억층에 침투해 데이터를 회수하는 사람이며, 머리에 통신/시야 인터페이스 칩이 박혀 있음.
- **브로커**: 의뢰주. 외부에서 통신으로만 등장.
- **NPC들**(광장): 정보 제공자, 거주민.

---

## 전체 진행

```
[접속구역] → [주인공집] → [광장] → [골목길]
```

## 연출 데이터 기준

> 시나리오는 자연어로 쓰되, 실제 구현은 아래 단위로 쪼개서 맞춘다.  
> 한 이벤트는 `작동방식` 1개와 `연출방식` 여러 개로 구성한다.

### 작동방식

| 타입 | 의미 | 현재 코드 대응 | 예시 |
|---|---|---|---|
| `Start` | 씬/구역 시작 시 자동 실행 | `SceneEventSequence.playOnStart` | 접속 시작 연출 |
| `Trigger` | 플레이어가 특정 영역에 들어오면 실행 | `SceneEventTrigger2D` | 점프/대시 안내, 접근 거부 |
| `Interact` | 플레이어가 가까이 가서 E를 누르면 실행 | `Interactable` | HOME코어, 단말기, 문, 칩장치 |
| `Logic` | 특정 조건이 만족되면 실행 | `WaitForEnemiesDead`, `TutorialGate` | 적 전멸 후 경로 해제 |
| `InputWait` | 특정 입력이 들어올 때까지 대기 | `WaitForInput` | 이동/점프/대시/공격 튜토리얼 |

### 연출방식

| 타입 | 의미 | 현재 코드 대응 | 상태 |
|---|---|---|---|
| `SystemLog` | 칩/시스템 메시지 표시 | `ShowSystemLog`, `HideSystemLog`, `FadeSystemLog` | 있음. 일반 로그 배경 분리됨 |
| `Comms` | 브로커/주인공/AI 대사 표시 | `ShowCommsLine`, `HideComms` | 있음 |
| `ScreenFade` | 전체 화면 암전/복귀 | `FadeOut`, `FadeIn` | 있음 |
| `Teleport` | 플레이어 위치 이동 | `TeleportPlayer` | 있음 |
| `CameraSnap` | 텔레포트 후 카메라 즉시 정렬 | `SnapCamera` | 있음 |
| `CameraShake` | 순간 흔들림 | `CameraShake` step → `SimpleCameraFollow.AddShake()` | 있음 |
| `Glitch` | 화면 글리치/색수차/노이즈 | `GlitchPulse`, `GlitchFade` | 있음 |
| `CameraFocus` | 적/중요 지점을 카메라로 보여주고 자동 복귀 (블로킹). 단독 강조용 | `CameraFocus` | 있음 |
| `SetCameraTarget` | 카메라 타겟만 즉시 변경 (논블로킹). null이면 플레이어로 복귀. FreezeTime/대사와 조합해 "비추는 동안 대사" 연출에 사용 | `SetCameraTarget` | 있음 |
| `PlayerLock` | 조작 잠금/해제 | `LockPlayer`, `UnlockPlayer` | 있음 |
| `TimeFreeze` | 전체 시간 정지/해제 (Time.timeScale=0). 적/플레이어/투사체 모두 정지. UI·카메라·대사는 unscaledDeltaTime으로 계속 동작 | `FreezeTime`, `UnfreezeTime` (PlayerSlowMotion 외부 freeze 우선권 사용) | 있음 |
| `ObjectActive` | 오브젝트 켜기/끄기 | `SetObjectActive` | 있음 |
| `ProgressBlocker` | 진행 차단/해제 | 현재 `TutorialGate` | 클래스명 유지, 시나리오 표현은 ProgressBlocker |
| `ProgressLog` | 회수 진행률/단계 표시 | `ShowProgressLog` | 있음 |
| `HoldProgress` | E를 누르는 동안 진행률 상승, 떼면 하락 | `HoldInteractProgress` | 있음 |

### 이벤트 데이터 형식

| 필드 | 의미 |
|---|---|
| `id` | 이벤트 고유 이름. 예: `access_02_memory_collapse` |
| `place` | 시나리오상 위치. 예: `접속구역/구간 2` |
| `activation` | 작동방식. `Start`, `Trigger`, `Interact`, `Logic` 중 하나 |
| `condition` | 실행 조건. 트리거 위치, 상호작용 대상, 적 전멸 등 |
| `steps` | 순서대로 실행할 연출방식 목록 |
| `blocksPlayer` | 실행 중 플레이어 조작을 막는지 |
| `notes` | 아직 코드에 없는 기능, 연출 강도, 수동 배치 메모 |

### 예시

| id | place | activation | condition | steps |
|---|---|---|---|---|
| `access_01_intro` | 접속구역/구간 1 | Start | 구역 시작 | PlayerLock → ScreenFade(검정 유지) → SystemLog(접속 정보) → Teleport → CameraSnap → ScreenFade(In) → PlayerLock 해제 → InputWait(Move) |
| `access_02_memory_collapse` | 접속구역/구간 2 | Trigger | 점프/회피 구간 진입 | Comms(기억층이 무너진다) → Glitch(약함) → CameraShake(약함) → SystemLog(SPACE) → InputWait(Jump) → SystemLog(↓ + ← / →) → InputWait(Roll) |
| `access_03_first_enemy` | 접속구역/구간 3 | Trigger | 첫 적 구간 진입 | FreezeTime → SetCameraTarget(적) → Delay → SystemLog([방어 개체 감지]) → Comms(앞에 하나/보여) → SetCameraTarget(null=플레이어) → Delay → UnfreezeTime → SystemLog(공격) → InputWait(Attack) |
| `access_04_enemy_group` | 접속구역/구간 4 | Trigger | 연속 전투 구간 진입 | SystemLog([접속 차단 활성화]) → GlitchPulse → FreezeTime → SetCameraTarget(적) → Delay → Comms(감시 개체 셋/숫자 세지 마) → SetCameraTarget(null) → Delay → UnfreezeTime |
| `access_05_ranged_enemy` | 접속구역/구간 5 | Trigger | 원거리 적 구간 진입 | FreezeTime → SetCameraTarget(적) → Delay → Comms(맞으면 접속이 흔들린다/맞으면) → SetCameraTarget(null) → Delay → UnfreezeTime → SystemLog(↓ + ← / → 회피) → InputWait(Roll) |
| `access_06_home_core` | 접속구역/구간 6 | Interact | HOME코어에서 E | LockPlayer → FreezeTime → SystemLog([회수 대상 확인]) → Comms(이 정도 보호를 걸/판단하지 마) → UnfreezeTime → SystemLog(E 길게 누르기) → HoldProgress(100%) → 접속 실패/강제 복귀 연출 |

## 접속구역 — 가상 침입 시퀀스

> 접속구역은 실제 방처럼 표현하지 않는다. 각 구간은 플레이 흐름을 나누기 위한 제작용 단위이며, 화면상으로는 기억 데이터 내부를 계속 침투하는 느낌으로 이어진다.

### 기억층 붕괴 연출

- 시작 시점: 구간 2 진입 대사 `기억층이 무너진다.` 직후.
- 기본 연출: 화면 글리치, 약한 카메라 흔들림, UI 텍스트 순간 깨짐.
- 강도 변화: 처음에는 짧고 약하게, 전투/회수 실패에 가까워질수록 더 자주 강하게.
- 플레이 영향: 조작을 방해할 정도로 흔들지 않는다. 판정과 카메라 추적은 유지하고, 시각/청각 압박만 준다.
- 추가 후보: 저주파 노이즈, 짧은 색수차, 프레임 스킵처럼 보이는 순간 끊김, 시스템로그 일부 글자 깨짐.

### 구간 1 — 진입 / 이동 튜토리얼

**연출**
1. 화면 검음.
2. 시스템로그 (한 줄씩):
   - `[접속 중...]`
   - `[대상: 채무자 047]`
   - `[회수 파일: HOME]`
   - `[침입 경로 확보]`
3. (검은 화면 유지) 플레이어를 공중 위치로 텔레포트, 카메라 스냅.
4. 페이드 인 → 플레이어 자유낙하 → 착지.
5. 브로커/주인공 통신:
   - 브로커: "들리나?"
   - 주인공: "잡음 심해."
   - 브로커: "파일 하나만 꺼내. 내용은 보지 말고."
   - 주인공: "늘 하던 대로."

**플레이**
- 시스템로그: `A / D : 이동`
- 이동 입력 대기.
- 브로커: "경로는 짧다. 멈추지 마."

### 구간 2 — 점프 / 회피 튜토리얼

**연출**
- 트리거 진입 시:
  - 브로커: "기억층이 무너진다."
  - 주인공: "그럼 빨리 끝내지."
  - 화면 글리치 + 짧은 카메라 흔들림 시작.

**플레이**
- 시스템로그: `SPACE : 점프` → 점프 입력 대기 → 로그 페이드아웃.
- 시스템로그: `↓ + ← / → : 회피` → 아래키 + 좌/우 입력 대기 → 로그 페이드아웃.

### 구간 3 — 첫 적

**연출**
- 적 등장 (이미 배치되어 있음).
- **시간 정지** (Time.timeScale=0, 적/투사체/플레이어 모두 정지. 대사·카메라·UI는 unscaledDeltaTime).
- 카메라가 첫 적 위치를 짧게 보여준 뒤 플레이어에게 돌아온다.
- 브로커: "앞에 하나."
- 주인공: "보여."
- **시간 해제**.
- 시스템로그: `마우스 좌클릭 : 공격`

**플레이**
- 적 전멸 → 다음 경로 해제.
- 주인공: "다음."

### 구간 4 — 연속 전투

**연출**
- 트리거 진입 → 진행 차단.
- 시스템로그: `[접속 차단 활성화]` 등 짧은 알림.
- 글리치 강도 잠깐 상승.
- **시간 정지**.
- 카메라가 적 3명 위치를 짧게 보여준 뒤 플레이어에게 돌아온다.
- 브로커: "감시 개체 셋."
- 주인공: "숫자 세지 마. 느려져."
- **시간 해제**.

**플레이**
- 적 N마리 전멸 → 진행 차단 해제.

### 구간 5 — 원거리 적 / 회피

**연출**
- **시간 정지**.
- 카메라가 원거리 적 위치를 짧게 보여준 뒤 플레이어에게 돌아온다.
- 시스템로그: `↓ + ← / → : 회피`
- 브로커: "맞으면 접속이 흔들린다."
- 주인공: "맞으면."
- **시간 해제**.

**플레이**
- 적 전멸 → 진행.

### 구간 6 — HOME코어 상호작용

**연출**
- HOME코어 근처 도달 → 시스템로그: `E : 상호작용`

**플레이**
- E 누름 → 시퀀스 시작.
- **시간 정지** (브로커/주인공 대사 동안).
- 주인공: "이 정도 보호를 걸 파일은 아닌데."
- 브로커: "판단하지 마. 회수해."
- **시간 해제**.
- 시스템로그: `E 길게 누르기 : HOME 회수`
- E를 누르고 있는 동안 접속 진행률이 오른다.
- E를 떼면 진행률이 내려가고 글리치는 사라진다.
- 진행률이 올라갈수록 글리치가 강해진다.
- 진행률 100% 도달 시 같은 HOME코어 이벤트 안에서 `접속 실패 / 강제 종료` 연출이 바로 이어진다.

### 구간 6 후반 — 접속 실패 / 강제 종료

> 별도 트리거를 두지 않는다. HOME코어 이벤트에 합쳐서 실행한다.

**연출**
- 시스템로그 (한 줄씩):
  - `[연결 불안정...]`
  - `[회수 실패]`
  - `[강제 접속 종료]`
- 강한 화면 글리치 + 카메라 흔들림 피크.
- 브로커: "뭐야, 왜 안 빠져?"
- 주인공: "파일이 심층에 물렸어."
- 브로커: "끊어. 지금은 못 뽑는다."
- 페이드아웃 → 텔레포트(주인공집 침대) → 페이드인.

## 주인공집

**연출**
- 페이드인으로 침대 위/방 안 등장.
- 시스템로그: `[접속 종료]`

**플레이**
- **단말기** 상호작용 (E) → 단말기 모니터 텍스트 표시. *반복 가능.*
- **거울** 상호작용 (E) → 거울 전용 시스템로그(주인공 자기인식/현재 상태 메시지). *반복 가능.*
- **문_광장으로** 상호작용 (E) → 텔레포트(광장). *반복 가능.*

> 세 오브젝트 모두 가까이 가면 `E : 상호작용` 시스템로그가 먼저 안내된다.

---

## 광장

**연출**
- 광장 진입 후 특정 영역 도달 → 시스템로그: `[접근 권한 없음]`

**플레이**
- **노점상 NPC** 상호작용 (E) → 노점상 대화. *반복 가능.*
- **게이트 물체** 상호작용 (E) → 게이트 안내 시스템로그. *반복 가능.*
  - 게이트 옆에 **AI NPC**가 배치되어 있으며, 게이트가 무엇인지 설명하는 대화를 한다. (게이트 상호작용과 별개 Interactable, 반복 가능)
- **행인 NPC** 상호작용 (E) → 행인 대화.
- **골목길 입구 트리거** 상호작용 (E) → 텔레포트(골목길). *반복 가능.*

> 모든 NPC/오브젝트는 가까이 가면 `E : 상호작용` 시스템로그가 먼저 안내된다.

## 골목길

**연출**
- 브로커와 직접 대면 대화 (여러 줄).
  - 1씬에서 회수 실패했던 **채무자 047** 건이 다시 화제로 올라온다.
  - 브로커가 "다시 들어가야 한다"는 취지로 재접속을 지시.

**플레이**
- **칩장치(채무자 047 칩)** 상호작용 (E) → 아래 시퀀스 순서로 재접속 연출 진행.

**시퀀스_칩접속 step 순서 (구현 기준)**
1. LockPlayer
2. Comms 브로커: "심층에 남은 인격이 있을 수 있다."
3. Comms 브로커: "말 걸지 마. 베고, 뽑고, 나와."
4. Comms 주인공: "늘 하던 대로."
5. HideComms
6. FadeOut (검은 화면 진입)
7. ShowSystemLog: `[접속 재개...]` / `[대상: 채무자 047]` / `[심층 침투 경로 확보]`
8. TeleportPlayer → **스폰_재접속_047** (같은 씬 내, 공중 위치로 미리 배치)
9. SnapCamera
10. FadeIn (검은 화면 해제 → 자유낙하 시야 노출)

## 현재 구현 기준

### 이미 있는 것
- ScreenFade (전환)

### 다음에 확장할 수 있는 것

1. **인트로 검은 화면 처리**
   - ScreenFade를 길게 유지해도 OK인지, 별도 인트로 backdrop을 둘지.

2. **시스템로그 — backdrop**
   - 완료 기준: 칩 메시지는 화면을 검게 만들지 않음. 일반 메시지는 텍스트만.
   - 필요하면 특정 연출에서만 `SystemLogPanel.useBackdrop`를 켠다.

3. **카메라 줌인**
   - 현재는 `CameraFocus`로 적 위치를 보여준다. 줌 배율 변화는 나중에 필요하면 추가한다.

4. **다중 대사 자동 진행**
   - 골목길에서 브로커가 여러 줄 연달아 말할 때 한 줄씩 step 만들기 귀찮음.
   - `ShowCommsDialogue(lines[])` 같은 step?

5. **사망 / 부활**
   - 죽으면 어디서 부활? 현재 룸 시작점?

6. **NPC 상호작용**
   - 광장 NPC는 Interactable 재사용으로 가능?

7. **단말기 모니터 텍스트**
   - 단말기 켜면 별도 UI(긴 텍스트)? 현재 MonitorText가 있는 듯.
