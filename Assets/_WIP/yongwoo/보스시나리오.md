# 보스 스테이지 시나리오 발췌

> 원본: `_archive/DEEP_DIVE_HOME_scenario.md`. 보스 작성에 필요한 핵심만 추렸다.
> 잡몹 구간(Room 1~6) 구성·튜토리얼 안내는 제외했다.

---

## 1. 스토리 핵심 (보스를 쓰기 위한 전제)

### HOME의 진실

| 브로커가 생각한 HOME | 실제 HOME |
|---|---|
| 거주권 키 | 가족과 살던 집의 기억 |
| 부동산 접근 권한 | 아이에게 남긴 음성 |
| 돈 되는 정보 | 돌아가고 싶었던 장소 |

> **핵심 대비:** 사람에게 가장 소중한 기억은, 시장에서는 가장 쓸모없는 데이터로 취급된다.

### 채무자 047

- 이미 사망/의식 붕괴된 인물
- 도시에서 쫓겨난 전직 노동자/기술자
- 가족과 살던 집을 잃음
- 죽기 전 `HOME`을 두뇌 칩에 숨김 → 브로커는 거주권 키로 오해, 실제는 가족 기억 백업

### 잔류 인격 = 보스

> `HOME` 파일을 지키기 위해 남은 채무자 047의 마지막 의지.

- 괴물이 아니라 "기억을 지키는 사람"
- 대표 톤: "그건 팔 물건이 아니야." / "그 기억만은 가져가지 마."

### 주인공의 변화 (보스전이 끼는 위치)

```
초반: 기억 = 돈 되는 데이터 / 대상자 = 회수 대상
↓ (보스전 = 전환점)
후반: 기억 = 누군가의 삶 / 대상자 = 사람이었다
```

## 2. 보스방 진입까지의 떡밥 (기억 조각)

본 스테이지 중간에 잡몹 구간 사이로 들어가는 2개의 회상.
플레이어가 보스 정체를 미리 짐작하게 만든다.

### 기억 조각 1
```
아이: 오늘부터 여기가 우리 집이야?
아버지: 그래. 작지만 우리 거야.

주인공: ...가족 기록?
브로커: 잡음이다. 무시해.
```

### 기억 조각 2
```
아이: 아빠, 도시는 왜 우리를 싫어해?
아버지: 싫어하는 게 아니야.
아버지: 우리가 돈이 없는 거지.

아이: 그럼 돈이 있으면 집에 갈 수 있어?

(주인공 침묵)

브로커: 거의 다 왔다. 감상은 나와서 해.
```

## 3. 보스전

### 보스 이름

**HOME의 문지기** / **잔류 인격: 채무자 047**

### 등장 연출

- 보스방 중앙에 문 하나
- 문 앞에 데이터 코어
- 주인공이 접근하면 인간 형태의 깨진 실루엣이 나타남

### 등장 대사
```
잔류 인격: 그건 팔 물건이 아니야.
브로커:    잔류 인격이다. 지워.
주인공:    대상자 047인가.
잔류 인격: 이름으로 부르지 마.
잔류 인격: 가져갈 거면, 그냥 데이터라고 불러.
```
→ 이 대사로 "단순한 적이 아니라 사람이었다"를 박는다.

### 패턴 (캡스톤 스코프: 3개면 충분)

| 패턴 | 설명 | 플레이어 대응 |
|---|---|---|
| 돌진 | 좌우 빠른 돌진 | 대시 회피 |
| 기억 장판 | 바닥 빛 장판 생성 | 점프 회피 |
| 파편 소환 | 기억 파편 1~2마리 소환 | 빠르게 처치 |
| 약점 노출 | 공격 후 잠깐 멈춤 | 공격 타이밍 |

- 페이즈 분리 없이 체력 3칸 느낌
- 후반에 속도만 살짝 증가

### 중간 대사

**체력 50% 이하**
```
잔류 인격: 나는 집을 남기려 했을 뿐이야.
브로커:    방어 반응이 강해진다. 빨리 끝내.
```

**체력 낮을 때**
```
잔류 인격: 문은... 열어둔다고 했는데...
```

## 4. 보스 처치 후 — HOME 회수 (Scene 7)

보스 사라짐 → 공간 조용해짐 → 데이터 코어 열림.

### 시스템 텍스트
```
[HOME 파일 접근 가능]
[내용 분석 중...]

거주권 키 데이터 없음
자산 데이터 없음
보안 암호 없음

정서 기억 백업 확인
```

### 대사
```
브로커: 뭐야.
브로커: 그냥 가족 기록이잖아.

주인공: 그래서 그렇게 지킨 건가.

브로커: 추억은 싸. 암호는 비싸고.
```

### 마지막 기억 재생
```
아이: 아빠, 문 열어둘게.
아이: 그러니까 꼭 돌아와.
```

(짧은 침묵 → 파일 회수)
```
[HOME 파일 회수 완료]
```

## 5. 엔딩 (Scene 8) — 보스전 다음의 마지막 비트

집에서 깨어남 → 단말기에 브로커 메시지 → 자동 전송.

```
[파일 전송 요청]
전송 대상: 브로커
파일명: HOME

[HOME 전송 중...]
[전송 완료]
```

```
브로커: 끝났나?
주인공: 끝났어.
브로커: 쓸모없는 파일이었군.
브로커: 보상은 절반만 지급한다.

[보상 지급: 60C]
[채무 잔액: 83,360C]

주인공: 사람 하나의 집값이 60C인가.
```

### 진짜 엔딩

화면 구석 로그 한 줄:
```
[미전송 데이터: 1KB]
voice_001: "아빠, 문 열어둘게."
```

→ HOME 전체는 넘겼지만 가장 작은 기억 조각 하나를 몰래 남겼다.

```
브로커: 전송 누락은 없겠지?
주인공: 없어.
```

(침묵 → 주인공이 방 문을 살짝 열어둠 → 암전)

```
END
```

## 6. 톤 가이드

### 주인공
- 무심, 짧은 말, 단정형
- 예: "늘 하던 대로.", "보여.", "다음.", "...이걸로 하루."

### 브로커
- 냉정, 돈 중심, 감정 무시
- 대표: "추억은 싸. 암호는 비싸고."

### 잔류 인격 (보스)
- 흐릿하지만 분명한 의지
- 짧고 끊기는 말투
- 대표: "그건 팔 물건이 아니야.", "그 기억만은 가져가지 마."
