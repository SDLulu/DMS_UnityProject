## 1. 스토리 핵심 (보스를 쓰기 위한 전제)

### HOME의 진실

| 브로커가 생각한 HOME | 실제 HOME |
|---|---|
| 거주권 키 | 가족과 살던 집의 기억 |
| 부동산 접근 권한 | 아이에게 남긴 음성 |
| 돈 되는 정보 | 돌아가고 싶었던 장소 |

> **핵심 대비:** 사람에게 가장 소중한 기억은, 시장에서는 가장 쓸모없는 데이터로 취급된다.

### 채무자 047

- 이미 사망/의식 붕괴된 인물
- 도시에서 쫓겨난 전직 노동자/기술자
- 가족과 살던 집을 잃음
- 죽기 전 `HOME`을 두뇌 칩에 숨김 → 브로커는 거주권 키로 오해, 실제는 가족 기억 백업

### 잔류 인격 = 보스

> `HOME` 파일을 지키기 위해 남은 채무자 047의 마지막 의지.

- 괴물이 아니라 "기억을 지키는 사람"
- 대표 톤: "그건 팔 물건이 아니야." / "그 기억만은 가져가지 마."

### 주인공의 변화 (보스전이 끼는 위치)

```
초반: 기억 = 돈 되는 데이터 / 대상자 = 회수 대상
↓ (보스전 = 전환점)
후반: 기억 = 누군가의 삶 / 대상자 = 사람이었다
```

## 2. 보스방 진입까지의 떡밥 (기억 조각)

본 스테이지 중간에 잡몹 구간 사이로 들어가는 2개의 회상.
플레이어가 보스 정체를 미리 짐작하게 만든다.

### 기억 조각 1
```
연출: 대사 없는 분위기 영상 재생 중에는 아빠/딸 기억 대사만 인게임 Comms로 겹쳐 출력. 영상이 끝난 뒤 주인공/브로커 반응 대사로 전환.

아이: 저 불빛들, 전부 집이야?
아버지: 그래. 언젠가 우리 창문에도 저런 빛이 켜질 거야.
아이: 그럼 문 열어두면 아빠가 바로 찾겠네.
아버지: 어디 있어도 돌아올 수 있게. 그게 집이니까.

--- 영상 종료 후 ---

주인공: ...가족 기록?
브로커: 잡음이다. 무시해.
```

### 기억 조각 2
```
연출: 대사 없는 분위기 영상 재생 중에는 아빠/딸 기억 대사만 인게임 Comms로 겹쳐 출력. 영상이 끝난 뒤 주인공/브로커 반응 대사로 전환.

아이: 아빠, 도시는 왜 우리를 싫어해?
아버지: 싫어하는 게 아니야.
아버지: 우리가 돈이 없는 거지.

아이: 그럼 돈이 있으면 집에 갈 수 있어?
아버지: 돈이 있으면... 문 앞까진 갈 수 있지.

--- 영상 종료 후 ---

(주인공 침묵)

브로커: 거의 다 왔다. 감상은 나와서 해.
```

## 3. 보스전

> **게임플레이 룰·수치·패턴 표·시퀀스 step·구현 매핑은 `보스전로직.md`로 분리(2026-05-23).** 이 섹션은 대사·서사·톤만 유지한다.

### 보스 이름

**HOME의 문지기** / **잔류 인격: 채무자 047**

### 정체와 톤

- 괴물이 아니라 "기억을 지키는 사람"
- P2의 2분열, P3의 3분열은 서사적으로 "남은 인격이 더는 하나로 버티지 못하고 역할별로 찢어지는 모습"
- 처치 후에는 슬픔·정적·짧은 침묵으로 이행. 승리감 연출 금지

### 등장 대사
```
잔류 인격: 그건 팔 물건이 아니야.
브로커:    잔류 인격이다. 지워.
주인공:    대상자 047인가.
잔류 인격: 이름으로 부르지 마.
잔류 인격: 가져갈 거면, 그냥 데이터라고 불러.
```
→ 이 대사로 "단순한 적이 아니라 사람이었다"를 박는다.

### P1 → P2 전환 대사 (변신 시점)

```
잔류 인격: 나는 집을 남기려 했을 뿐이야.
```
> (원래 체력 50% 중간 대사 위치를 변신 시점으로 이전.)

### P2 → P3 전환 대사

P2 분열체가 무너지고 3분열로 재구성되는 시점:
```
잔류 인격: 나눠도... 남는 게 있어.
```

### P3 마지막 대사

마지막 분열체가 무너지기 직전 한 줄:
```
잔류 인격: 문은... 열어둔다고 했는데...
```

### 처치 직후 대사

```
브로커: 나왔어. 빠져.
주인공: ...
```

> 등장·전환·처치 step 시퀀스 구성은 `보스전로직.md` §6 참고.

## 4. 보스 처치 후 — HOME 회수 (Scene 7)

마지막 타격 → 보스 HP 바 숨김 → 화면이 짧게 하얗게 번짐 → 보스가 아직 완전히 사라지기 전 대사 없는 회상 영상(아버지가 딸을 떠올리고 문을 열고 나옴) → 잔류 인격 마지막 대사 → 보스 사망 이펙트와 함께 소거 → HOME 코어가 공중으로 떠오름 → 기존 HOME 분석 대사.

### 잔류 인격 마지막 대사
```
잔류 인격: 문을 열어둔다고 했지.
잔류 인격: 내가 너무 늦었다.
잔류 인격: 미안하다. 아빠가... 집을 잃어버렸다.
```

### 시스템 텍스트
```
[잔류 인격 신호 감쇠]
[인격 흔적 소거]
[HOME 코어 부상]
[회수 가능]

[HOME 파일 접근 가능]
[내용 분석 중...]

거주권 키 데이터 없음
자산 데이터 없음
보안 암호 없음

정서 기억 백업 확인
```

### 대사
```
브로커: 뭐야.
브로커: 그냥 가족 기록이잖아.

주인공: 그래서 그렇게 지킨 건가.

브로커: 추억은 싸. 암호는 비싸고.
```

### 회수
```

```

## 5. 엔딩 (Scene 8) — 보스전 다음의 마지막 비트

현재 구현 방향: 별도 엔딩 영상 없이, HOME 회수 후 주인공을 `스폰_주인공집`으로 이동시킨 다음 글리치를 걷고 집 배경 위에서 시스템로그/Comms로 인게임 처리.

```
[파일 전송 요청]
전송 대상: 브로커
파일명: HOME

[HOME 전송 중...]
[전송 완료]
```

```
브로커: 끝났나?
주인공: 끝났어.
브로커: 쓸모없는 파일이었군.
브로커: 보상은 절반만 지급한다.

[보상 지급: 60C]
[채무 잔액: 83,360C]

주인공: 사람 하나의 집값이 60C인가.
```

### 진짜 엔딩

화면 구석 로그 한 줄:
```
[미전송 데이터: 1KB]
voice_001: "아빠, 문 열어둘게."
```

→ HOME 전체는 넘겼지만 가장 작은 기억 조각 하나를 몰래 남겼다.

```
브로커: 전송 누락은 없겠지?
주인공: 없어.
```

(통신창 닫힘 → 침묵 → 주인공이 방 문을 살짝 열어둠 → 암전)

```
END
```

`SPACE` 입력 시 타이틀 씬으로 돌아간다.

## 6. 톤 가이드

### 주인공
- 무심, 짧은 말, 단정형
- 예: "늘 하던 대로.", "보여.", "다음.", "...이걸로 하루."

### 브로커
- 냉정, 돈 중심, 감정 무시
- 대표: "추억은 싸. 암호는 비싸고."

### 잔류 인격 (보스)
- 흐릿하지만 분명한 의지
- 짧고 끊기는 말투
- 대표: "그건 팔 물건이 아니야.", "그 기억만은 가져가지 마."
