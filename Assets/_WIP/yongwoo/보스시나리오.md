## 1. 스토리 핵심 (보스를 쓰기 위한 전제)

### HOME의 진실

| 브로커가 생각한 HOME | 실제 HOME |
|---|---|
| 거주권 키 | 가족과 살던 집의 기억 |
| 부동산 접근 권한 | 아이에게 남긴 음성 |
| 돈 되는 정보 | 돌아가고 싶었던 장소 |

> **핵심 대비:** 사람에게 가장 소중한 기억은, 시장에서는 가장 쓸모없는 데이터로 취급된다.

### 채무자 047

- 이미 사망/의식 붕괴된 인물
- 도시에서 쫓겨난 전직 노동자/기술자
- 가족과 살던 집을 잃음
- 죽기 전 `HOME`을 두뇌 칩에 숨김 → 브로커는 거주권 키로 오해, 실제는 가족 기억 백업

### 잔류 인격 = 보스

> `HOME` 파일을 지키기 위해 남은 채무자 047의 마지막 의지.

- 괴물이 아니라 "기억을 지키는 사람"
- 대표 톤: "그건 팔 물건이 아니야." / "그 기억만은 가져가지 마."

### 주인공의 변화 (보스전이 끼는 위치)

```
초반: 기억 = 돈 되는 데이터 / 대상자 = 회수 대상
↓ (보스전 = 전환점)
후반: 기억 = 누군가의 삶 / 대상자 = 사람이었다
```

## 3. 보스전

### 보스 이름

**HOME의 문지기** / **잔류 인격: 채무자 047**

### 게임플레이 디자인 (2026-05-23 확정)

> 시나리오의 옛 패턴 4종(돌진/기억 장판/파편 소환/약점 노출)은 폐기. 카타나제로식 페이즈 단계적 구조 + Cuphead식 고정 아레나로 재정의.

| 항목 | 결정 |
|---|---|
| 보스 수 | 최종 보스 1개 |
| 정체 | 채무자 047 잔존 인격 |
| 아레나 | **Cuphead식 고정 카메라 단일 방** |
| HP 모델 | **P1 5타 → 변신 → P2 (분열체 각 5타 = 10타) = 총 15타** |
| 페이즈 | 2개 (P1 → 변신 → P2) |
| 슬로우 게이지 | 게임 전반 자동 회복 룰만 사용. **보스전 중 리필·보너스 없음** |
| 소환물 | 없음 (분열체는 P2 본체 변신, 별도 잡몹 아님) |
| 사망 부활 | **보스 방 입구, P1부터 완전 재시작** |
| BGM | 보스 전용 1곡, P1→P2 전환 시 변주/증폭 |

#### P1 — 본체

| 항목 | 값 |
|---|---|
| 외형 | 인형 형태 추상체, 얼굴 없음 |
| 무브셋 | **직선 탄막 3패턴** — 단발 / 연사 / 확산 |
| 행동 사이클 | 공격 → 텔레포트 → 공격 (잠시 사라졌다 재출현) |
| 처치 조건 | 본체 근접 5타 |

#### P2 — 분열체 거울 쌍

| 항목 | 값 |
|---|---|
| 변신 | P1 본체가 둘로 쪼개짐 (서사: "남은 인격이 숨겼던 진짜 모습") |
| 구조 | **동질 거울 쌍** — 외형 동일, 행동 비대칭 |
| 무브셋 | 분열체A 2패턴 + 분열체B 2패턴 = **총 4패턴** |
| 행동 사이클 | 각자 P1 룰 유지 (공격 후 텔레포트) |
| 처치 조건 | 분열체 각 5타 = 총 10타 |

### 패턴 디테일 — P1 (1차 시안, 2026-05-23)

> 플레이어 행동 역산 기반. 핵심 제약:
> - 대시 거리 3.5u, **쿨 2초** → 사이클 ≤ 2s면 대시 단독 회피 불가, 점프/구르기/공간이동 강요
> - 구르기 0.36s 무적, 거리 ~3u (지상 한정)
> - 슬로우 자원 5칸 (1칸 = 1초 가정), `Hp UI` 칸 5개 재활용
> - 칼 데미지 1, 쿨 0.28s. 사거리는 콜라이더 (시안 가정 1.0~1.5u)

| # | 패턴 | 텔레그래프 (예고) | 선딜 | 액티브 | 후딜 | 사이클+텔포 | 회피 옵션 |
|---|---|---|---|---|---|---|---|
| P1-1 | **단발 직선탄** | 0.6s — 보스→플레이어 빨간 조준선 | 0.2s | 탄속 14u/s, 직선 1발 | 0.5s | 1.3 + 텔포 0.4 = **1.7s** | 점프 / 좌우 1보 / 구르기 |
| P1-2 | **연사** | 0.7s — 노란 발사 자세 | 0.1s | 0.15s 간격 4발, 탄속 12u/s, 동일 직선 | 0.6s | 1.4 + 0.4 = **1.8s** | 슬로우 1칸 → 4발 사이 통과 / 대시 측면 우회 (쿨 회복분 사용) |
| P1-3 | **확산 5way** | 0.9s — 부채꼴 5방향 가이드라인 | 0.15s | 5발 동시, 각도 30°, 탄속 10u/s | 0.7s | 1.75 + 0.4 = **2.15s** | 슬로우 1칸 → 틈 찾기 / 보스 근접해 부채꼴 안쪽으로 구르기 / 점프 |

**P1 행동 로직:**
- 패턴 선택은 의사난수 가중치 (단발 0.5 / 연사 0.3 / 확산 0.2) — 단순/명확/한복불가 보장
- 한 사이클 종료 → **텔레포트 (0.4s 페이드인/아웃)** → 다음 패턴
- 텔레포트 위치: 아레나 4모서리 + 중앙 위 1지점 = 5후보 중 직전 위치 제외 무작위

### 패턴 디테일 — P2 (1차 시안, 2026-05-23)

> P1 사이클 유지하되 거울 쌍 비대칭 분배. **분열체A = 근접 견제형 (빠름)**, **분열체B = 원거리 지역거부형 (느림·광역)**.
>
> 두 분열체는 각자 독립 사이클로 동시 행동. 동시 텔레그래프 충돌 룰: **한쪽 액티브 중이면 다른쪽은 텔레포트/이동만 가능, 새 텔레그래프 시작 금지.** 둘의 텔레그래프 시작이 0.3s 이내로 겹치면 늦게 시작한 쪽이 0.3s 지연.

#### 분열체 A — 근접 견제형

| # | 패턴 | 텔레그래프 | 선딜 | 액티브 | 후딜 | **사이클+텔포** | 회피 옵션 |
|---|---|---|---|---|---|---|---|
| P2-A1 | **대시 베기** | 0.5s — 보스→플레이어 빨간 방향선 + 자세 변화 | 0.15s | 대시 5u, 베기 판정 0.25s | 0.5s | 1.4 + 0.4 = **1.8s** | 점프 (대시는 지상 직선) / 구르기 무적 / 슬로우+측면 빠짐 |
| P2-A2 | **빠른 단발** | 0.4s 짧은 조준선 | 0.1s | 탄속 18u/s, 1발 | 0.4s | 0.9 + 0.4 = **1.3s** | 점프 / 1보 회피 / 구르기. 슬로우 안 써도 회피 가능해야 함 |

#### 분열체 B — 원거리 지역거부형

| # | 패턴 | 텔레그래프 | 선딜 | 액티브 | 후딜 | **사이클+텔포** | 회피 옵션 |
|---|---|---|---|---|---|---|---|
| P2-B1 | **7way 확산** | 0.9s 부채꼴 가이드 | 0.15s | 7발 동시, 각도 25°, 탄속 10u/s | 0.7s | 1.75 + 0.5 = **2.25s** | 슬로우 1~2칸 / 보스 근접 안쪽 구르기 / 점프 |
| P2-B2 | **지연 폭발 장판** | 0.6s — 바닥 2~3곳에 빛 표식 | — | 표식 1.0s 후 0.3s 폭발 판정 (반경 1.5u) | 0.6s | 1.9 + 0.4 = **2.3s** | 표식 밖으로 이동 (가장 단순) / 점프 안 통함 (지면 광역) — **위치 강제용** |

#### P2 행동 로직

- 두 분열체 모두 패턴 종료 → 0.4~0.5s 텔레포트 → 다음 패턴.
- 분열체별 패턴 가중치: A-1 0.4 / A-2 0.6, B-1 0.5 / B-2 0.5.
- **위치 분담**: A는 플레이어 ±5u 이내로 텔포 선호, B는 ±8u 이상 멀리 텔포 선호. 둘이 같은 사분면에 안 모이도록 텔포 후보에서 상대 위치 제외.
- 한쪽 분열체가 처치되면 남은 한쪽은:
  - 텔포 쿨다운 -0.1s
  - 패턴 가중치 살짝 광역 쪽으로 (남은 한 명이 압박 강화). 단 사이클 시간은 그대로 유지 (난도 폭주 방지).
- P2 진입 직후 0.7s는 두 분열체 모두 패턴 봉인 (변신 직후 휴지). 처음 패턴은 분열체A부터 시작.

#### 슬로우 자원 사용 동기

P2 전체에서 슬로우 5칸 자원이 가장 의미 있는 구간:
- **P2-B1 + P2-A2 동시 진행**: 광역 확산 + 빠른 단발 사이를 슬로우 1~2칸으로 빠져나가기
- **P2-B2 폭발 직전 + P2-A1 대시 베기**: 장판 사이 좁은 안전지대에서 대시베기 회피 → 슬로우 2칸 가치 큼

> 5칸 한 번에 다 쓰면 P2 절반은 슬로우로 통과 가능. 자동 회복 속도(1칸/N초)는 P2 1바퀴(약 8~10s)에 1~2칸 회복되도록 1칸/4s 1차 가정.

### 확정 가정 (2026-05-23, 구현 후 플레이로 재조정)

> 빌드 퍼스트 원칙. 일단 굳히고 구현 → 플레이 → 수치 튜닝.

## 6. 톤 가이드

### 주인공
- 무심, 짧은 말, 단정형
- 예: "늘 하던 대로.", "보여.", "다음.", "...이걸로 하루."

### 브로커
- 냉정, 돈 중심, 감정 무시
- 대표: "추억은 싸. 암호는 비싸고."

### 잔류 인격 (보스)
- 흐릿하지만 분명한 의지
- 짧고 끊기는 말투
- 대표: "그건 팔 물건이 아니야.", "그 기억만은 가져가지 마."
