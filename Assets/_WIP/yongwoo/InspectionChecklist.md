# 플레이어 / 보스 검사 체크리스트

## 플레이어

- [ ] 오른쪽 이동 시 오른쪽을 본다
- [ ] 왼쪽 이동 시 왼쪽을 본다
- [ ] 공격 판정이 비주얼 방향과 같은 쪽에 생긴다
- [ ] 플레이어 공격이 자기 자신을 맞히지 않는다
- [ ] 점프가 너무 빡빡하지 않고, 코요테 타임과 점프 버퍼가 체감된다
- [ ] 낙하 속도와 점프 컷이 자연스럽다
- [ ] 공격 애니메이션이 지나치게 길게 잠기지 않는다
- [ ] 죽은 뒤 정상 위치에서 다시 살아난다

## 보스

- [ ] `보스 소환` 버튼 클릭 시 보스가 실제로 생성된다
- [ ] `보스 리셋` 버튼 클릭 시 기존 보스가 사라지고 새로 생성된다
- [ ] 보스가 플레이어를 바라보는 방향이 맞다
- [ ] 보스가 너무 멀거나 너무 가까우면 거리를 다시 조절한다
- [ ] 모든 패턴이 `예고 -> 실행 -> 후딜` 흐름을 가진다
- [ ] 돌진 공격이 자기 자신을 맞히지 않는다
- [ ] 내려찍기 공격이 자기 자신을 맞히지 않는다
- [ ] 투사체가 플레이어를 맞히면 사라진다
- [ ] 투사체가 벽이나 바닥에 닿으면 사라진다
- [ ] 체력 구간에 따라 페이즈가 바뀐다
- [ ] 죽은 뒤 다시 살아나도 패턴 상태가 초기화된다

## 저장

- [ ] 플레이 중 플레이어 튜닝값을 바꾸면 즉시 런타임에 반영된다
- [ ] 플레이 종료 후 다음 실행에서도 플레이어 값이 유지된다
- [ ] 플레이 중 보스 튜닝값을 바꾸면 즉시 런타임에 반영된다
- [ ] 플레이 종료 후 다음 실행에서도 보스 값이 유지된다

## UI

- [ ] 플레이어 체력바가 현재 체력에 맞게 길이와 색이 바뀐다
- [ ] 보스 체력바가 현재 체력에 맞게 길이와 색이 바뀐다
- [ ] 버튼 클릭을 위한 EventSystem이 정상 동작한다

## 구조

- [ ] 플레이어 기준 자산은 `Player.prefab`으로 이해 가능하다
- [ ] `Player.prefab`을 열면 `Visual`, `Sensors`, `Debug` 역할이 바로 읽힌다
- [ ] 보스 기준 자산은 `Boss.prefab`으로 이해 가능하다
- [ ] `Boss.prefab`을 열면 `Visual`, `Sensors`, `Debug`, `ProjectileSpawn` 역할이 바로 읽힌다
- [ ] 디버그룸은 전투 테스트를 위한 연결과 UI만 담당한다
- [ ] 튜닝값의 소스 오브 트루스가 prefab 하나로 유지된다
